# Invernadero Inteligente de Bajo Consumo Implementando FreeRTOs

Actualmente la agricultura, enfrenta diversos desafíos relacionados con la gestión y optimización de los recursos hídricos, esto se debe a factores como la variabilidad climáticas y la necesidad de aumentar la eficiencia en los procesos de cultivo Los sistemas de riego tradicional tienden a depender mucho de la intervención humana, , lo que puede ocasionar un suministro inadecuado de esta misma, por ende afectar el cultivo. En este contexto, surge este proyecto, cuyo objetivo  es diseñar e implementar un prototipo de invernaderos inteligente de bajo consumo, el cual permite automatizar los procesos de monitoreo de variables ambientales y mejorar la eficiencia del riego mediante el uso de tecnologías embebidas. Se empleó la Metodología de Diseño de Sistemas Embebidos proporcionada por el docente como base. Como resultado, se obtiene  un prototipo capaz de identificar las condiciones de humedad del cultivo y activar o desactivar la bomba de agua según las condiciones detectadas. En conclusión la implementación de un sistema embebido con gestión de tareas en tiempo real permite mejorar la automatización del riego, optimizar el consumo hídrico y proporcionar una solución tecnológica orientada a la agricultura inteligente.
